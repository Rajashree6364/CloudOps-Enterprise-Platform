# CloudBite - CloudOps Enterprise Food Delivery Platform
This repository contains the complete frontend web application and backend infrastructure code for CloudBite.

## Folder Structure
- `index.html`: Interactive web application featuring AWS Cognito Sign-In, AI Chef Recommendations, Autonomous Drone Dispatch, and Real-time Telemetry.
- `.github/`: CI/CD GitHub Actions pipeline workflows.
- `app/`: Microservices application code and Dockerfile.
- `kubernetes/`: AWS EKS Kubernetes deployment manifests.
- `terraform/`: Infrastructure-as-Code Terraform scripts for AWS VPC, EKS, and RDS.
